# 試用說明（TRY-IT）

> 目標：在你自己的 Chrome 上，把 TradingView 當下圖表的 OHLC 丟給 TypeSafe 的 Jev 做一次「做多／觀望／做空」預測。
> 這份是**人工驗收步驟**（Task 09 清單 ①–⑦ 的執行版）。

---

## 0. 前置

| 項目 | 內容 |
| --- | --- |
| 擴充資料夾 | 本專案 clone 下來的 `<專案根>\extension`（例：`C:\dev\jev-tradingview-signal\extension`） |
| TypeSafe API key | 在 <https://console.typesafe.ai> 申請後貼到擴充設定頁；若你另有 `jev-proxy` 之類的既有設定，key 也存在它的 `.env`（**別貼進聊天室、別 commit**） |
| 帳號 | TradingView 免費帳號即可（未登入也能看到圖，但免費方案延遲較高） |

---

## 1. 載入未封裝擴充（只在第一次做）

1. Chrome 網址列輸入 `chrome://extensions`
2. 右上角打開 **開發者模式**
3. 點 **載入未封裝項目** → 選 `...\jev-tradingview-signal\extension`（**選 extension 這層，不是專案根**）
4. 清單應出現 **Jev Signal 0.1.0**，且**沒有紅色「錯誤」按鈕**

> 若出現錯誤訊息，把訊息貼給我（不要截到 key）。

## 2. 填 API key

1. 在 `chrome://extensions` 的 Jev Signal 卡片 → **詳細資料** → **擴充功能選項**
2. 貼上 API key → 模型選 `jev-latest` → K 棒數量 300 → 派生特徵打勾
3. 按 **儲存**，再按 **測試連線** → 應出現成功訊息（失敗會顯示中文錯誤）

## 3. 開一張 TradingView 圖表

1. 開 `https://www.tradingview.com/chart/`（或直接開你平常的圖）
2. **等圖表畫完**（K 棒出現、報價在跳）
3. 這時擴充已在背景旁聽該分頁的行情 WebSocket——**不需要按任何東西**

## 4. 開側邊面板看狀態

點工具列的 **Jev Signal** 圖示（或右鍵圖示 → 開啟側邊面板）。
面板狀態列應顯示類似：

```
圖表：BINANCE:BTCUSDT · 15 · 301 根 · buffer total 301
```

- 看到 **根數 ≥ 50** 且「預測」鈕**亮起**＝連線正常
- 若顯示 **圖表：等待中** → 見下方疑難排解

## 5. 按「預測」

按下去後，面板會依序顯示 `預測中 → 結果`，正常約 **1–3 秒**（Jev 端實測 1003ms）：

- **方向**：做多 / 觀望 / 做空（附三個機率）
- **未來 10 根**：機率值
- **多頭趨勢強度／空頭趨勢強度**：各一個 0–4 分數＋強度描述（none～very strong）
- 可展開 **原始 JSON**（含 token 用量與成本估算）

> 這是「當下這一刻」的模型輸出，**不是投資建議**；面板底部固定有免責語。

---

## 6. 疑難排解

| 症狀 | 可能原因 | 處理 |
| --- | --- | --- |
| 面板一直「等待中」 | 沒在 TV 圖表分頁／圖還沒載完／剛重載過頁面 | 切到 TV 分頁、等圖載完，等 2 秒（面板每 2 秒輪詢）|
| 「預測」鈕灰掉 | 收到的 K 棒不足 50 根 | 等圖載完，或把圖的週期／可見範圍調整讓它多抓一點 |
| 顯示 auth 錯誤 | key 打錯或過期 | 到選項頁重填、按測試連線 |
| 顯示 rate/過載 | TypeSafe 429/529 | 等幾十秒再按（擴充會自動退避重試）|
| 顯示 offline | 網路斷 | 恢復網路後再按 |
| 圖表分頁換了符號，面板數字沒變 | 面板顯示的是「最近有送資料的分頁」 | 等新分頁的圖載完（面板會自動跟上），或按重新載入 |

---

## 7. 已知限制（刻意不做的）

- 只送 **OHLCV + 本地派生特徵**（MA20/50、RSI14、動量…），**不抓 TradingView 上的指標**（第一期範圍）
- **手動**按鈕觸發，不自動連續預測
- 不自動下單、不接券商 API、不存交易紀錄、不做回測
- 一次只服務「最近送資料的 TV 分頁」

---

## 8. 出問題時請回報這些（不含 key）

1. 面板狀態列文字
2. 面板上的錯誤訊息
3. `chrome://extensions` → Jev Signal →「錯誤」按鈕裡的訊息（若有）
4. 你開的圖表網址（symbol + interval 即可）

---

## 6. 多指標真機驗收（F9/F10；**選做**——已自動化驗收通過，此為你自己圖表的手動抽驗，約 2 分鐘）

1. `chrome://extensions` → **重新載入**「Jev Signal」（或重開 Chrome）。
2. 開你的 TradingView 圖表（掛上你常用的指標，例如 BB／ALMA／RSI；等 K 棒滿 250 根）。
3. 點擴充圖示開 Panel → 找折疊區「**指標映射**」：
   - [ ] 列出圖上**每個指標**各一個輸入框（自動名稱，如 `BB(30)`）——數量與圖上一致
   - [ ] 隨便一個改名（如「布林通道」）→ 點別處**失焦即存** → 下次預測的原始 payload `studies[].name` 用新名；重開 Panel 名稱還在
   - [ ] 把某個輸入框**清空**→ 失焦 → 自動回到自動名
   - [ ] 按某列「**✕**」→ 該列移入「已排除（N）」→ 預測的 payload **不含**該指標；按「**復原**」還原（自訂名稱保留）
4. 按「**開始預測**」：
   - [ ] 結果區出現「**本次附帶指標**」摘要（每指標一行：名稱＋末值＋值數）
   - [ ] 「原始 payload」展開 → `studies` 陣列每指標一筆（id/name/rawName/columns/values），`values` 長度＝bars 長度（同窗口對齊，缺值 null）
   - [ ] 成本顯示 **$0.001–0.002**（≤ $0.005）
5. 回報：6 個勾勾＋payload 截圖（或哪項不符）。
