jev-signal — TradingView × Jev 預測 Chrome Extension

個人工具・MV3・零依賴・手動按鈕 → 一次盤勢判斷（多/觀/空＋校準機率）
TradingView 分頁（注入 world:MAIN 旁聽自家 WebSocket → mem 幀 → OHLCV 滚动緩衝）
        → content bridge → service worker（快照→派生特徵→state 組裝）
        → POST api.typesafe.ai /v1/systemone（jev-latest，三題：direction/up_10_bars/trend_strength）
        → Side Panel：方向徽章＋機率條＋confidence＋token 成本＋原始 JSON

已定案決策

  • 直打 TypeSafe 官方 API，繞過 jev-proxy（零後端改動）
  • 取數＝頁面 ws 旁聽（不發自製訂閱、不改 send）
  • 第一期只旁聽已載入 K 棒（600–1000 根），預測取最近 300 根
  • state＝OHLCV＋本地派生特徵（MA20/50、RSI14、動量），開關可關
  • 不做：下單、回測、TV 指標數值、持久化、上架

你需要準備

  1. TypeSafe API key（console.typesafe.ai 申請）→ 之後貼在擴充設定頁，本機環境變數 JEV_API_KEY 供驗證腳本用
  2. Chrome 保持可登陸 TradingView（Task 01 取證與 Task 09 驗收要用真實圖表）
  3. 簽核本總覽＋docs 四件套 → 說「簽核，開始 Task 01」
成本預估：300 根 K 棒 ≈ 1 萬 token ≈ 每次預測 < $0.0005；Jev 延遲 70–500ms，按鈕體驗接近即時。
